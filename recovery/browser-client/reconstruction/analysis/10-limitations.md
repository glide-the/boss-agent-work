# 10 Limitations

- No original repository, Source Map or `sourcesContent` was found.
- Static analysis cannot prove dynamic Proxy/reflection/transport behavior.
- Third-party inlined code must be separated conservatively.
- Existing Chrome trust rules can prevent a workspace bundle from using privileged bridges.
- The historical interaction task confirms identity and connectivity, not BOSS website end-to-end actions.
- The canonical production build is independent of `scripts-bak`; however, the checked-in formatted compatibility kernel still contains unresolved first-party/third-party module boundaries and must not be described as the authors' complete TypeScript source.
- Mock differential tests passed, but no real Chrome or BOSS website action was executed without explicit authorization.
