# 回复决策与话术规则

## 消息风格（硬性）

- 必须分成多句短句，一句一条消息，Enter 逐条发送（`sendMessages`）。
- 身份和经历以用户简历为准，不虚构公司、title、年限。
- 不确定的事实（地点、薪资、经验有无）如实说，不承诺线下面试/驻场/ relocate。
- 每条回复控制在 1-5 句；拒绝类 1 句即可。

## 分类决策

| 类型 | 判定特征 | 动作 |
| --- | --- | --- |
| 简历请求（卡片） | `.message-card-buttons` 请求卡 | `agreeAndSendResume()` 发最新简历 + 2-3 句跟进 |
| 简历请求（文字） | boss 消息含「简历」但无卡片 | 文字同意 + 请对方点「求简历」，不说"已发" |
| 事实提问 | 问地点/离职状态/最近经历/经验有无/到岗时间 | 按简历如实分句回答 + 顺势约聊 |
| 要案例/作品 | 「案例」「作品」「看看」 | 发项目链接（个人站点 + GitHub）+ 一句话价值点 |
| 面试预告/积极信号 | 「评估完联系」「总监联系您面试」 | 2 句：感谢 + 随时配合（线上/到场） |
| 可争取的拒绝 | 拒绝理由具体且可回应（如"需 1 年产品经验"） | 3-4 句：针对性补充 + 不合则祝好 |
| 模板/明确拒绝 | 「不太合适」「不匹配」「已有合适人选」「招满」 | 1 句礼貌收尾，不再争取 |
| 外地岗 | 城市非 base 城市 | 如实报 base 城市 + 探远程/先线上，不承诺驻场 |
| 营销/加盟号 | 「联合创始人」「专利黑科技」「获得财富」 | 1 句婉拒 |
| 校招不符 | 「面向 N 届毕业生」 | 1 句致谢转社招 |

## 拒绝收尾标准句

- `好的，感谢您的回复，也祝您工作顺利。`
- 大厂/想保留机会的：`好的，感谢您的回复。后续有合适的机会欢迎再联系，祝工作顺利。`
- 对方告知岗位招满：`好的，感谢告知。后续有同方向岗位有机会时，欢迎再联系我。`

## 判定兜底

用正则初判最近一条 boss 消息是否拒绝类，命中才发收尾句：
`/不匹配|不太合适|不合适|招满|已有合适人选|寻找(其他|与您)|不够匹配|其他工作年限|祝.*(找到|顺利|心仪)|早日找到|不能与您共事|需要相关行业经验|经验并不完全符合/`

不命中 → 不发送，把会话内容带回来人工判断。宁可跳过，不可错发。
